# 🎲 Classic Ludo Game in Java

Welcome to my **Classic Ludo Game**, built entirely in Java with a simple, interactive GUI!  
This project demonstrates core Java concepts like OOP, GUI programming, and game logic implementation.

---

## 📌 Features

✅ Classic Ludo gameplay with 4 players  
✅ Turn-based moves & pawn navigation  
✅ Complete board layout with paths  
✅ Win condition & game over screen  
✅ Built with Java Swing/AWT for GUI  
✅ Includes `.jar` file for easy execution

---

## 🗂️ Project Structure

LUDO/
├── Build_Player.java
├── GameMoves.java
├── GameScreen.java
├── Layout.java
├── Path.java
├── Pawn.java
├── Player.java
├── LUDO.jar
├── .classpath
├── .project
└── .gitignore


- **Build_Player.java** – Handles player creation & setup  
- **GameMoves.java** – Core logic for pawn moves  
- **GameScreen.java** – Main game window & rendering  
- **Layout.java** – Board layout & design  
- **Path.java** – Defines pawn paths  
- **Pawn.java** – Pawn behavior & state  
- **Player.java** – Player attributes & turn handling  
- **LUDO.jar** – Compiled runnable JAR file

## 🚀 How to Run

1. Clone the repository:  
   ```bash
   git clone https://github.com/Aalekh09/ludo.git
2. Compile the Java file
    javac *.java
3. Run the Game
   java GameScreen
